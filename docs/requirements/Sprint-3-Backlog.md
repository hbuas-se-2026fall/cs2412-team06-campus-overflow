## 四、完成定义（DoD）

- **代码**：新增逻辑均有单元测试；PR 至少 1 人评审后由 PO 合并；不残留 `TODO(S3)`
- **质量**：前端 `npm run typecheck && npm run build` 绿；后端领域层覆盖率门禁 0.70 生效（本次 Sprint 起）
- **文档**：本 Backlog、ADR（≥1 份）、Retro 纪要、演示讲稿合并进 `main`
- **演示**：`main` 上可复现完整 5 分钟演示路线
- **CI**：`main` 流水线全绿（含端到端集成测试）
