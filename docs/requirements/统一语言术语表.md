# 统一语言术语表（Ubiquitous Language）

> 中英对照，团队统一使用，避免理解歧义

---

## 用户与身份
| 中文 | 英文 | 说明 |
|------|------|------|
| 用户 | User | 系统的使用者，已注册的学生 |
| 游客 | Guest | 未登录的访问者 |
| 用户名 | Username | 用户的唯一标识 |
| 密码 | Password | 登录凭证（加密存储） |
| 认证 | Authentication | 验证用户身份的过程 |
| 角色 | Role | 用户的权限角色（学生、管理员） |
| 声誉分 | Reputation | 用户的积分，根据投票和采纳动态变化 |

## 问题与回答
| 中文 | 英文 | 说明 |
|------|------|------|
| 问题 | Question | 用户发布的待解答的疑问 |
| 问题标题 | QuestionTitle | 问题的简短概括 |
| 问题内容 | QuestionBody | 问题的详细描述 |
| 提问者 | Questioner | 发布问题的用户 |
| 回答 | Answer | 对问题的解答 |
| 回答者 | Answerer | 发布回答的用户 |
| 问题详情页 | QuestionDetailPage | 显示问题和所有回答的页面 |
| 问题列表 | QuestionList | 所有问题的列表展示 |

## 互动与投票
| 中文 | 英文 | 说明 |
|------|------|------|
| 投票 | Vote | 用户对问题/回答的评价 |
| 点赞 | Upvote | 正面评价，+1分 |
| 点踩 | Downvote | 负面评价，-1分 |
| 采纳 | Accept | 提问者标记某个回答为最佳答案 |
| 最佳回答 | AcceptedAnswer | 被提问者采纳的回答 |
| 投票者 | Voter | 参与投票的用户 |

## 标签与分类
| 中文 | 英文 | 说明 |
|------|------|------|
| 标签 | Tag | 给问题分类的关键词 |
| 标签筛选 | TagFilter | 按标签筛选问题列表 |
| 标签页 | TagPage | 显示某标签下所有问题的页面 |

## 通知
| 中文 | 英文 | 说明 |
|------|------|------|
| 通知 | Notification | 系统给用户的消息提醒 |
| 未读通知 | UnreadNotification | 用户还没看过的通知 |

## 工程与流程
| 中文 | 英文 | 说明 |
|------|------|------|
| 聚合根 | AggregateRoot | 聚合的入口，保证业务不变式 |
| 值对象 | ValueObject | 没有唯一标识，通过属性判断相等 |
| 实体 | Entity | 有唯一标识，生命周期内不变 |
| 领域事件 | DomainEvent | 领域中已经发生的有意义的事情 |
| 限界上下文 | BoundedContext | 业务边界，划分模块的依据 |
| 业务不变式 | BusinessInvariant | 业务规则，任何时候都必须成立 |
| 完成定义 | DefinitionOfDone (DoD) | 任务完成的标准 |
| 产品待办列表 | Product Backlog | 所有需求的优先级列表 |
| Sprint待办列表 | Sprint Backlog | 当前迭代要做的任务 |
| 用户故事 | User Story | 从用户视角描述需求 |
| 验收标准 | Acceptance Criteria | 需求完成的判断条件 |

---

**总计：40个术语**
