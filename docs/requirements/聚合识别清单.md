# 聚合识别清单

> 版本：v1.0
> 日期：2026-10-22

---

## 聚合1：Question（问题聚合）

| 项目 | 内容 |
|------|------|
| **聚合名** | Question |
| **聚合根实体** | Question（问题） |
| **包含值对象** | Tag（标签）、QuestionTitle（问题标题）、QuestionBody（问题内容） |
| **关键不变式** | 1. 问题标题不能为空，长度10-200字<br/>2. 问题内容不能为空，长度至少20字<br/>3. 一个问题至少要有1个标签<br/>4. 只有提问者本人可以编辑/删除自己的问题 |

---

## 聚合2：Answer（回答聚合）

| 项目 | 内容 |
|------|------|
| **聚合名** | Answer |
| **聚合根实体** | Answer（回答） |
| **包含值对象** | AnswerBody（回答内容） |
| **关键不变式** | 1. 回答内容不能为空，长度至少10字<br/>2. 不能回答自己提的问题<br/>3. 只有回答者本人可以编辑/删除自己的回答<br/>4. 一个问题只能有一个被采纳的回答 |

---

## 聚合3：Vote（投票值对象）

| 项目 | 内容 |
|------|------|
| **聚合名** | Vote |
| **聚合根实体** | Vote（投票） |
| **包含值对象** | VoteType（投票类型：UPVOTE/DOWNVOTE） |
| **关键不变式** | 1. 每个用户对每条内容只能投1票<br/>2. 投票类型只能是 UPVOTE 或 DOWNVOTE |

---

## 聚合4：User（用户聚合）

| 项目 | 内容 |
|------|------|
| **聚合名** | User |
| **聚合根实体** | User（用户） |
| **包含值对象** | Reputation（声誉分）、Username（用户名） |
| **关键不变式** | 1. 用户名唯一<br/>2. 声誉分不能为负数 |
