## 五、Sprint 3 DoD（完成定义）

- [ ] 承诺故事 US-001~007 在 main 可演示，链路：注册/登录 → 提问 → 列表 → 详情 → 回答 → 投票 → 采纳。

- [ ] 每个功能 Task 经 PR 评审通过后合并 main，无 main 直推。
- [ ] 冒烟用例在联调环境执行并回填结果；失败项登记到看板。
- [ ] 文档同步：接口/行为变更更新对应 docs；评审清单在实战中修订。

- **范围蔓延**：声誉、通知、搜索不进本 Sprint 承诺；新增需求先入 Sprint 4 Backlog。
