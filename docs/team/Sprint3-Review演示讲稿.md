## 2:00-3:00 演示一：提问与互动（从操作）

操作顺序（提前登录好账号）：

1. 打开问题列表页 → "按最新排序，支持分页"
2. 点开一条问题 → "详情页显示回答按票数排序"
3. 提交一条回答 → "回答立即出现在列表"
4. 在回答下发表评论 → "支持两级回复，@提及会触发通知"

台词：*"这一页是问题详情，回答、评论、投票都在这里。"*

## 3:00-4:00 演示二：投票、采纳与声誉（龙/何操作）

操作顺序：

1. 对回答点赞 → 票数 +1；再点踩 → 变成 -1（**改投**）；再点一次 → 撤销（0）
2. 回到提问者视角，采纳该回答 → 出现"已采纳"标识
3. 切到"我的通知" → 红点出现（采纳通知）
4. 切到排行榜 → 该回答作者声誉 +15（采纳奖励）

台词：*"投票支持改投和撤销，声誉按'新效果减旧效果'结算；采纳后声誉异步到账，通过事件驱动，不阻塞主流程。"*

## 4:00-5:00 演示三：标签、搜索、排行榜收尾（从操作）

操作顺序：

1. 标签筛选：点"Java"标签 → 只显示该标签问题
2. 搜索框输入关键词 → 返回按相关度排序的结果
3. 排行榜页 → Top 用户与声誉分

台词：*"标签、搜索、排行榜都已接通。以上是 Sprint 3 的增量，欢迎老师和同学提问。"*

## 应急预案

| 现场故障 | 处理 |
| --- | --- |
| 后端无响应 | 切到预录的演示视频继续讲，说明"现场环境网络波动" |
| 某个页面白屏 | 跳过该功能，直接讲代码/测试截图（CI 全绿截图） |
| 数据库数据被改乱 | 使用预置演示账号（demo1~demo3），不现场注册 |
