## 答辩要点（跨团队答辩占 25%，提前准备）

| 可能被问 | 回答要点 |
| --- | --- |
| 为什么用 Outbox 而不是直接在采纳时调声誉接口？ | 跨上下文不能有同步依赖，采纳主流程不能因为声誉模块慢/挂而回滚；Outbox 保证事件最终投递，配合至少一次投递 + 消费端幂等 |
| 幂等怎么保证？ | `ReputationLedgerService.record` 首行按 `(sourceEventId, userId, reason)` 查重，重复投递直接返回；`UserRegisteredEvent` 处理器先 `findByUserId` 判断 |
| 覆盖率怎么算的？ | JaCoCo 按模块统计 LINE 覆盖率，`backend/pom.xml` 里门禁 0.70，低于阈值构建失败 |
| 排行榜为什么分四档？ | 周/月/学期 ZSET 按事件时间累加，分别给 15/40/200 天 TTL；总榜读账户累计分，不受 TTL 影响 |
| 自问自答为什么是 0 分？ | 规则手册里 `acceptedDelta(questionAuthor, answerAuthor)` 同一人返回 0，且 `delta > 0` 才授徽与结算悬赏 |
