## P0 - MVP核心功能

### US-001 用户注册与登录
- 作为游客，我可以注册账号并登录系统
- 验收标准：
  - 用户名+密码注册，密码加密存储
  - 登录后跳转到问题列表页
  - 未登录用户不能提问、回答、投票

### US-002 发布问题
- 作为登录用户，我可以发布一个新问题
- 验收标准：
  - 问题标题必填，至少10字
  - 问题内容必填，支持Markdown
  - 选择至少1个标签
  - 提交后跳转到问题详情页

### US-003 浏览问题列表
- 作为游客，我可以浏览所有问题
- 验收标准：
  - 列表按最新发布排序
  - 显示问题标题、作者、发布时间、回答数、浏览数
  - 支持分页，每页20条

### US-004 查看问题详情
- 作为用户，我可以查看问题详情和所有回答
- 验收标准：
  - 显示问题完整内容
  - 按投票数排序显示回答
  - 显示作者信息和发布时间

### US-005 回答问题
- 作为登录用户，我可以对问题发表回答
- 验收标准：
  - 回答内容必填
  - 提交后立即显示在回答列表
  - 回答作者不能回答自己的问题（可选）

## P1 - 重要功能

### US-006 投票功能
- 作为登录用户，我可以给问题/回答点赞或点踩
- 验收标准：
  - 每个用户对每条内容只能投1票
  - 显示当前总票数
  - 取消投票后票数相应减少

### US-007 采纳最佳回答
- 作为问题提问者，我可以采纳一个回答为最佳答案
- 验收标准：
  - 只有提问者本人能采纳
  - 被采纳的回答有特殊标识
  - 采纳后不能取消（可选）

### US-008 标签系统
- 作为用户，我可以给问题打标签，按标签筛选问题
- 验收标准：
  - 预设标签：Java、前端、数据库、算法、其他
  - 问题列表可按标签筛选
  - 标签页显示该标签下所有问题

### US-009 用户声誉系统
- 作为用户，我的声誉分根据投票和采纳动态变化
- 验收标准：
  - 内容（问题或回答）被点赞 +10 分，被点踩 −2 分
  - 回答被采纳，回答作者 +15 分；若回答者与提问者是同一人则不加分
  - 每日正向投票得分上限 200 分（扣分不受上限约束）
  - 用户主页显示声誉分和等级
- 注：以上数值以代码 `ReputationRulebook`（`ACCEPTED=15`、`UPVOTE=10`、`DOWNVOTE=-2`、`DAILY_VOTE_CAP=200`）为准。本文档原写“点赞 +5 / 采纳 +10”，与实现不一致，2026-11-11 按代码修订。

## P2 - 锦上添花功能

### US-010 排行榜
- 作为用户，我可以查看声誉排行榜
- 验收标准：
  - 按声誉分排序显示Top 50用户
  - 显示排名、用户名、声誉分

### US-011 搜索功能
- 作为用户，我可以搜索问题关键词
- 验收标准：
  - 按标题和内容模糊搜索
  - 搜索结果按相关度排序

### US-012 通知系统
- 作为用户，我会收到回答、采纳、投票的通知
- 验收标准：
  - 右上角显示未读通知数
  - 点击通知跳转到对应页面

## Sprint 规划

### Sprint 1（需求与设计）
- 完成用户访谈
- 用户故事地图
- 事件风暴、领域建模
- 输出：需求文档、领域模型、上下文映射

### Sprint 2（工程骨架）
- 后端DDD多模块工程搭建
- 前端React+TS工程搭建
- 打通第一个端到端接口：发布问题
- 输出：可运行的前后端骨架

### Sprint 3（核心功能）
- 完成US-001到US-007
- 单元测试覆盖率≥70%，核心聚合≥90%
- PR代码评审流程跑通
- 输出：可演示的核心功能版本

### Sprint 4（部署上线）
- Docker容器化
- CI/CD流水线
- 监控告警
- 输出：线上可访问的完整系统
