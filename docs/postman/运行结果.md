## 结论

全链路（注册→登录→提问→回答→投票→采纳→查声誉）**全部跑通**，状态码符合 RESTful 语义（201 创建 / 200 成功 / 204 无内容）。

- 回答被采纳后，回答者声誉从 0 → 25（投票 +1 分 + 采纳奖励 + 徽章事件异步结算）
- 徽章 `FIRST_ANSWER` 和 `FIRST_ACCEPTED` 由 ReputationEventHandlers 异步消费 `AnswerSubmittedEvent` / `AnswerAcceptedEvent` 后正确发放
- 本次运行同时验证了 T6 BUG#2 修复：采纳后问题列表的"已采纳"标志会立即刷新（listCache.invalidateAll 生效）
