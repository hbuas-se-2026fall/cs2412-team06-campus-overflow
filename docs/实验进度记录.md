| 组件 | 端口 | 说明 |
|------|------|------|
| MySQL 8.0.46 | 3307 | 独立实例与独立数据目录，未改动本机 3306 的 MySQL80 服务；库 `campus_overflow`，账号 `campus` / `campus_dev_pwd` |
| Redis 5.0.14.1 | 6379 | 便携版，承担会话、问题列表缓存、浏览量、排行榜与登录限流 |
| 后端 | 8080 | JDK 21 编译的 `co-bootstrap` fat jar；`/actuator/health` = UP |
| 前端 Vite | 5173 | `npm run dev`，`/api` 代理到 8080 |

已实测跑通的链路：注册 → 登录 → 提问 → 回答 → 采纳 → 列表已采纳标记刷新 → 排行榜声誉 +15。

本地运行有两个已知坑，排障时先看这里：
1. `application.yml` 中 `characterEncoding=utf8mb4` 与 Connector/J 9.1.0 不兼容，启动抛 `UnsupportedEncodingException: utf8mb4`，需覆盖成 `UTF-8`。
2. Windows 版 Redis 的 `INFO server` 返回 `executable:c:\...\redis-server.exe`，Spring 解析抛 `Malformed \uxxxx encoding`，导致 `/actuator/health` 一直 DOWN，需关闭 redis 健康指标或换 Linux 版 Redis。
