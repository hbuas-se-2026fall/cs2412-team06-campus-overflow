本地运行有两个已知坑，排障时先看这里：
1. `application.yml` 中 `characterEncoding=utf8mb4` 与 Connector/J 9.1.0 不兼容，启动抛 `UnsupportedEncodingException: utf8mb4`，需覆盖成 `UTF-8`。
2. Windows 版 Redis 的 `INFO server` 返回 `executable:c:\...\redis-server.exe`，Spring 解析抛 `Malformed \uxxxx encoding`，导致 `/actuator/health` 一直 DOWN，需关闭 redis 健康指标或换 Linux 版 Redis。
